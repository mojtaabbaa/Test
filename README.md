# Codegen Pro WordPress Theme

A modern, professional WordPress theme inspired by codegen.com with full Elementor support and advanced customization options.

## Features

### Design & Appearance
- Modern dark theme design similar to codegen.com
- Fully responsive for all devices
- Attractive animations and visual effects
- Professional typography with Inter font

### Technical Features
- Full Elementor compatibility
- Advanced settings panel in WordPress admin
- WordPress Customizer with live preview
- SEO optimization and performance enhancements

### User Experience
- Responsive mobile menu
- Back to top button
- Configurable preloader
- Smooth scrolling for internal links

### Settings Panel
- Color and font settings
- Hero section management
- Social media settings
- Custom CSS/JS code
- Import/Export settings

## Installation

1. Download the theme files
2. Upload to `/wp-content/themes/codegen-pro/` directory
3. Activate the theme from WordPress admin
4. Go to **Appearance > Theme Options** for advanced settings
5. Use **Appearance > Customize** for quick settings
